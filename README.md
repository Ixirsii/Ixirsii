# Hey, I’m Ryan

Usually `Ixirsii` online.
I’m a software engineer with 8+ years of experience building web applications,
APIs, and distributed systems, mostly with Java and Kotlin.

Outside work, I like understanding how systems fit together,
from application code down to the operating system and hardware.
This has led to Rust, FreeBSD, and an increasingly indefensible number of things
in my house requiring maintenance.

I build things to understand how they work.
Whether this results in usable software is between me and the repository.

Away from the keyboard, I’m usually reading fantasy, listening to music,
or playing games with friends.

- **[Valorant Randomizer][2]** —
  An agent and loadout randomizer for when choosing your own bad ideas gets
